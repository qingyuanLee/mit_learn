## 1. 一句话问题

**在一个没有中心、身份匿名、节点随意加入退出的网络里，怎么让所有人对同一本"交易账本"达成一致，且不让人双花（double-spending）？**

---

## 2. 核心机制

### 2.1 区块链（Blockchain）

- 每个 block 包含：
  - 一批交易
  - 前一个 block 的哈希
  - 一个 nonce（工作量证明）
- 所有节点按最长链（most cumulative work）工作。

### 2.2 工作量证明（PoW）

- 矿工要找一个 nonce，使得 `Hash(block header) < target`。
- target 动态调整，让全网平均 10 分钟出一个块。
- 谁先找到，谁广播，所有人接受。

### 2.3 交易

- 每个交易由发送者用私钥签名。
- 节点验证签名、余额、是否双花。
- 矿工把合法交易打包进 block。

### 2.4 双花问题

- 如果有人把同一笔钱发给两个人，两个交易在网络里。
- 矿工只会把其中一个打包进最长链（或两个都进，但后一个会被节点拒绝，因为余额已花）。
- **6 个确认**：6 个块之后，回滚成本极高，交易基本不可逆。

---

## 3. 与 PBFT 的对比

| | PBFT | Bitcoin |
|---|---|---|
| 节点身份 | 已知 | 匿名 |
| 节点数 | N 固定（4-10） | 动态（几万） |
| 决策成本 | 消息复杂度 O(N²) | **算力成本（PoW）** |
| 一致性 | 强一致 | **概率一致**（越长越确定） |
| 容错 | f < N/3 | 恶意算力 < 50% |

> Bitcoin 把"共识成本"从消息数量转成了算力，这是它能在匿名网络工作的关键。

---

## 4. 51% 攻击

- 如果一个实体控制了全网 50% 以上算力，它可以：
  - 把自己的交易回滚（双花）
  - 阻止别人的交易被确认
- 但不能偷钱（因为签名还在）。

## 5. FAQ

**Q: 比特币为什么慢（10 分钟一个块）？**
A: 这是 PoW 难度调整的结果，平衡了安全性和出块速度。

**Q: 比特币是线性一致吗？**
A: 不是。它是**概率一致**——交易有一定概率被回滚，6 个确认后概率极低。

**Q: 矿工为什么愿意挖矿？**
A: 出块奖励（新币）+ 交易费。
