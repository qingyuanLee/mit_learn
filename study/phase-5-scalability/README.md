# 阶段 5：扩展性（Scalability）

> **这个阶段要解决的问题：** 数据量太大、QPS 太高，单机扛不住怎么办？
> **为什么学这个：** 共识解决了"正确"，复制解决了"可靠"，扩展性解决了"大"。三个都搞懂，你就理解了现代分布式系统。

---

## 学习目标

读完这个阶段，你应该能：

1. 区分 range partition 和 hash partition
2. 解释一致性哈希的原理
3. 理解分片 + 配置变更的挑战
4. 说明缓存层怎么挡在数据库前面

## 核心内容

### 1. 分片策略
| 策略 | 优点 | 缺点 |
|---|---|---|
| Range Partition | 范围查询快 | 热点 |
| Hash Partition | 分布均匀 | 范围查询慢 |
| 一致性哈希 | 迁移少 | 实现复杂 |

### 2. 配置变更
- 为什么分片不能随便改？
- 新旧 config 怎么过渡？
- ShardMaster 怎么管理配置？
- 数据迁移怎么保证一致性？

### 3. 缓存
- 缓存层的作用
- 缓存一致性（写穿、写回、失效）
- 缓存雪崩、击穿、热点
